# Spain self-employed residence: checklist and AI agent

This is an evidence-led workflow for a Spanish `residencia y trabajo por cuenta propia` application. It guides an agent through route selection, private-document review, technical preflight and, only when explicitly authorized, official-portal submission.

It distinguishes the art. 191.3 modification from a work-enabled residence, including a digital nomad visa (`EX-26`, four years), switches from no lucrativa (art. 191.4) and from student status (art. 190.3), a cuenta propia renewal (`EX-07`, four years), the initial outside-Spain visa route (`EX-07`) and separate family cases. The tool never makes a legal decision, signs, sends network requests, or claims that a fee payment is a filing.

Start with the [Spanish README](README.md), then use the [agent prompt](prompts/agent-workflow.md), [routes, deadlines and fees](docs/routes-and-sources.md), [per-route checklists](docs/checklists.md), [special cases](docs/special-cases.md), [laws and official links](docs/legal-basis.md), [workflow](docs/workflow.md), [case/CLI schema](docs/cli.md), and [submission sequence](docs/submission.md). Keep every case outside the repository.

# ВНЖ Испании по cuenta propia: чек-лист и ИИ-агент

Репозиторий помогает собрать доказательства, выбрать маршрут, проверить приватный пакет и при явном разрешении пользователя подать его через официальную sede. Это не шаблон «одной заявки для всех»: отдельно ведутся модификация art. 191.3 / EX-26, первичная EX-07 из-за границы и семейное дело.

Скрипт проверяет только технику файлов. Он не заменяет юридическую проверку, не подписывает, не платит, не отправляет заявку и не обещает одобрение. Начните с [испанской документации](README.md), [схемы приватного дела](docs/cli.md) и [prompt для агента](prompts/agent-workflow.md); реальные документы хранятся вне репозитория.

# Dónde reunir documentos

Esta tabla sirve para recopilar evidencia, no para convertir cada fila en requisito. Confirmar aplicabilidad mediante la ruta y fuente vigente; si la Administración comprueba un dato de oficio, no exigir por defecto una certificación nueva.

| Grupo | Evidencia habitual | Cómo obtenerla | Uso |
| --- | --- | --- | --- |
| Identidad | Pasaporte completo, TIE, resolución/concesión original | Original del usuario; portal solo con acceso autorizado | Base o prueba práctica según ruta |
| Fiscal | Situación censal, declaraciones y estar al corriente | [AEAT](https://sede.agenciatributaria.gob.es/Sede/ayuda/consultas-informaticas/certificados-tributarios-ayuda-tecnica/certificado-encontrarse-corriente-obligaciones-tributarias.html), con sesión del usuario o descarga que entregue | Evidencia práctica de actividad/obligaciones; confirmar si se comprueba de oficio |
| Seguridad Social | Vida laboral, alta RETA, estar al corriente | [Importass](https://portal.seg-social.gob.es/), con autorización de sesión o documento original | Evidencia práctica de actividad/obligaciones; confirmar si se comprueba de oficio |
| Banco | Extracto/certificado original | Banco o archivo que entregue el usuario; no convertir CSV derivado en original | Prueba práctica para recursos, inversión o actividad cuando aplica |
| Negocio | Alta, contratos, facturas, licencias, cualificación, plan | Originales del usuario, registros o fuentes autorizadas | Requisito o apoyo según ruta/actividad |
| Exterior | Antecedentes, títulos, registro civil | Emisor competente; traducción jurada y apostilla/legalización cuando corresponda | Condicional; revisar norma, país y fecha |
| Municipio | Padrón, vivienda, licencias | Ayuntamiento concreto de residencia, revalidado para ciudad y fecha | Solo si ruta familiar/actividad/provincia lo pide |
| Familia | Pasaportes, TIE, vínculo, concesión y firma/representación | Originales autorizados y emisor competente | Caso individual, nunca sustituye el expediente principal |

Un agente puede localizar, descargar o transcribir solo con acceso autorizado y deja constancia de fuente, fecha, alcance y hash. La persona conserva control de certificados, banco, firma, MFA y portal. No introducir datos de otro familiar para rellenar su expediente sin legitimación comprobada.

Para renovación de actividad por cuenta propia, contrastar también la [Hoja 15](https://inclusion.gob.es/web/migraciones/w/15.-renovacion-de-la-autorizacion-de-residencia-temporal-y-trabajo-por-cuenta-propia) con la ruta real. No se fija aquí una caducidad municipal o de certificado: depende del documento, administración y fecha de uso.
